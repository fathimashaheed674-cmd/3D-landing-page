# Sony WH-1000XM6 — 3D Scrollytelling Landing Page

A cinematic, Apple-level scrollytelling landing page engineered for the **Sony WH-1000XM6** flagship noise-cancelling headphones. Built with **React**, **Vite**, **Tailwind CSS**, and **HTML5 Canvas** for smooth 60fps hardware-accelerated image-sequence playback.

Inspired by luxury tech brand experiences and typography inspired by modern brutalist and editorial design systems.

---

## ✨ Features

- **Interactive 120-Frame Explosion & Reassembly**: Scroll-linked HTML5 Canvas playing a smooth disassembling technical diagram and reassembly sequence.
- **Direct-on-Background Typography**: Clean, uncluttered layout with zero blurry containers over the 3D model.
- **Editorial Typography**: Powered by **Syne** (bold display), **Outfit** (body copy), and **Space Grotesk** (technical telemetry and monospace badges).
- **Interactive Acoustic Simulator**: Real-time mode switching between Active Noise Cancelling (-42 dB), Adaptive Ambient Sound, and Wind Noise Reduction with live frequency wave visuals.
- **Custom Dual Cursor**: Trailing cursor dot and outline with mix-blend difference mode and interactive hover states.
- **Industrial Finishes Showcase**: Interactive finish selector for Matte Black, Platinum Silver, and Midnight Navy.
- **Apple-Style Tech Specs Table**: Tabbed engineering specifications for Acoustics, Noise Cancellation, Battery (40h ANC, 3m fast charge), Connectivity, and Eco Packaging.
- **Pre-Order Drawer**: Complete with edition selector, complimentary custom laser engraving, and order confirmation flow.

---

## 🚀 Tech Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Rendering**: HTML5 Canvas (high-DPI, requestAnimationFrame lerp interpolation)
- **Fonts**: Syne, Outfit, Space Grotesk

## 🛠️ Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/fathimashaheed674-cmd/3D-landing-page.git
cd 3D-landing-page
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
